# Руководство по градиентам KPI карточек

Это руководство описывает новые возможности градиентов для KPI карточек в компоненте `SupplyManagementPage`.

## Новые возможности

### 1. Пользовательские градиенты

Вы можете задать собственный градиент с помощью свойства `customGradient`:

```tsx
<KPICard
  title="Пользовательский градиент"
  value="94.2%"
  trend={2.1}
  icon={<IconTruck size={24} />}
  color="blue" // Игнорируется при customGradient
  customGradient="linear-gradient(45deg, #ff006e, #8338ec, #3a86ff)"
/>
```

### 2. Направления градиентов

Используйте свойство `gradientDirection` для изменения направления:

```tsx
<KPICard
  title="Градиент вправо"
  value="94.2%"
  trend={2.1}
  icon={<IconTruck size={24} />}
  color="blue"
  gradientDirection="to-r" // Доступные: to-r, to-br, to-b, to-bl, to-l, to-tl, to-t, to-tr
/>
```

#### Доступные направления:
- `to-r` - вправо (90deg)
- `to-br` - вниз-вправо (135deg) - по умолчанию
- `to-b` - вниз (180deg)
- `to-bl` - вниз-влево (225deg)
- `to-l` - влево (270deg)
- `to-tl` - вверх-влево (315deg)
- `to-t` - вверх (0deg)
- `to-tr` - вверх-вправо (45deg)

### 3. Анимированные градиенты

Добавьте анимацию с помощью свойства `animated`:

```tsx
<KPICard
  title="Анимированный градиент"
  value="94.2%"
  trend={2.1}
  icon={<IconTruck size={24} />}
  color="blue"
  animated={true}
/>
```

### 4. Тематические наборы градиентов

Используйте предустановленные темы с помощью свойства `theme`:

```tsx
<KPICard
  title="Океанская тема"
  value="94.2%"
  trend={2.1}
  icon={<IconTruck size={24} />}
  color="blue"
  theme="ocean"
/>
```

#### Доступные темы:

##### `default` (по умолчанию)
Стандартные яркие градиенты

##### `ocean`
Сине-голубые оттенки, напоминающие океан
- Подходит для: логистики, доставки, морских перевозок

##### `sunset`
Теплые оттенки заката
- Подходит для: продаж, доходов, позитивных метрик

##### `forest`
Природные зеленые оттенки
- Подходит для: экологии, устойчивости, роста

##### `cosmic`
Космические фиолетово-синие оттенки
- Подходит для: технологий, инноваций, будущего

##### `warm`
Теплые розово-оранжевые оттенки
- Подходит для: комфорта, клиентского сервиса

##### `cool`
Холодные сине-фиолетовые оттенки
- Подходит для: аналитики, данных, точности

## Комбинирование возможностей

Вы можете комбинировать различные возможности:

```tsx
<KPICard
  title="Комплексный пример"
  value="94.2%"
  target="95%"
  trend={2.1}
  icon={<IconTruck size={24} />}
  color="green"
  theme="ocean"
  gradientDirection="to-r"
  animated={true}
  size="lg"
/>
```

## Приоритет свойств

1. `customGradient` - имеет наивысший приоритет, игнорирует `color` и `theme`
2. `theme` - применяется к базовому цвету из `color`
3. `gradientDirection` - изменяет направление любого градиента
4. `animated` - добавляет анимацию к любому градиенту

## Производительность

### Анимации
- Анимации автоматически отключаются для пользователей с `prefers-reduced-motion: reduce`
- На мобильных устройствах анимации замедляются для экономии батареи
- Используйте анимации умеренно - не более 2-3 анимированных карточек на экране

### Пользовательские градиенты
- Избегайте слишком сложных градиентов с множеством цветов
- Предпочитайте 2-3 цвета в градиенте для лучшей производительности

## Доступность

### Контрастность
- Все предустановленные градиенты обеспечивают достаточный контраст для белого текста
- При использовании `customGradient` убедитесь в достаточном контрасте
- Минимальный контраст: 4.5:1 для обычного текста, 3:1 для крупного текста

### Анимации
- Анимации автоматически отключаются при `prefers-reduced-motion: reduce`
- Анимации не содержат мигающих эффектов

## CSS классы

Для дополнительной кастомизации доступны CSS классы в `gradientAnimations.css`:

- `.gradient-shift` - плавное движение градиента
- `.gradient-pulse` - пульсация размера
- `.gradient-rotate` - вращение градиента
- `.gradient-wave` - волновая анимация
- `.theme-ocean`, `.theme-sunset`, etc. - тематические классы

## Отладка

### Проверка градиентов
1. Откройте DevTools
2. Найдите элемент карточки
3. Проверьте CSS свойство `background`
4. Убедитесь, что анимация применяется через класс или inline стили

### Частые проблемы
1. **Градиент не отображается**: Проверьте синтаксис CSS градиента
2. **Анимация не работает**: Убедитесь, что CSS файл импортирован
3. **Плохая производительность**: Уменьшите количество анимированных элементов
